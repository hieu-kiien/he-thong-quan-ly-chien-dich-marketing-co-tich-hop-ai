# Báo cáo dự án AIA331-80300

Kho này được đồng bộ trực tiếp từ thư mục dự án hiện tại trên máy.

## Hồ sơ hiện tại

- `Bao_Cao_AIA331_80300_ICTU_V5/`: nguồn LaTeX, hình, DDL, DOCX và PDF của báo cáo.
- `đề tài của tôi.png`: ảnh yêu cầu đề tài.
- `yêu cầu của môn học.png`: ảnh tiêu chí môn học.

Bản DOCX dùng để chỉnh sửa, bản PDF dùng để xem và in, còn `ddl.sql` là phần
thiết kế cơ sở dữ liệu được đưa vào hồ sơ báo cáo.

Các file phụ sinh khi biên dịch LaTeX được bỏ qua bằng `.gitignore`.
