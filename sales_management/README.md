# Sales Management

He thong quan ly ban hang duoc xay dung bang Django theo kien truc MVT.

> **Trạng thái:** `IMPLEMENTED` một phần. Model nghiệp vụ và CRUD danh mục đã có
> nội dung; phần lớn route/view/test, báo cáo, export và tích hợp AI vẫn chưa
> hoàn chỉnh.

## Cong nghe

- Python 3.12+
- Django
- PostgreSQL
- Django ORM
- HTML5, CSS3, JavaScript
- Bootstrap 5

## Khoi chay

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
