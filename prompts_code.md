# Prompt sinh mã cho Marketing AI

Khi yêu cầu AI sinh code, luôn cung cấp `project_id`, ID yêu cầu, module đích,
input/output, validation, quyền, test bắt buộc và trạng thái `PROPOSED` nếu code
chưa chạy. Không yêu cầu AI tự ghi dữ liệu hoặc tự publish nội dung marketing.

Ví dụ task: “Sinh test cho `FR-008` tính CTR và chi phí/chuyển đổi; kiểm tra mẫu
0 view, click vượt view và nhiều ngày metric.”
